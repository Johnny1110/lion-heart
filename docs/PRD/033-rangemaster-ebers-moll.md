# PRD 033: `rangemaster` — 三節點 Ebers–Moll 鍺電晶體 booster（Phase 05 第二顆）

狀態：**已實作（2026-07-29）— 待使用者耳朵驗收**
日期：2026-07-29
里程碑：Tone Revolution · Phase 05（`docs/tone_revolution/phase/05-fuzz-transistor-family.md` §2.3）
關聯：**ADR 035**（電晶體建模法，含對參考實作的修正）、ADR 033（器件參數來自器件的政策）、
PRD 032（`big-muff`，共用 `blocks::transistor`）
新增 ADR：**ADR 035**（與 PRD 032 / 034 共用）

## 1. 背景與決策

這是家族裡**第一顆非線性就是電晶體本身**的踏板。`big-muff` 的電晶體被線性化成一個
增益常數，因為那顆踏板削波的是回授二極體；Rangemaster **除了電晶體什麼都不削**。

它的兩個機制就是兩個接面：

- **截止（cutoff）**——訊號把基極拉離偏壓，射-基接面關掉，一個極性被硬切；
- **飽和（saturation）**——集極擺回基極附近，集-基接面**導通**，另一個極性被軟壓。

兩者**不是鏡像**，所以單顆電晶體長出肥厚的二次諧波，而二極體對長不出來。曲線可以模仿
形狀；只有器件模型能跟上「工作點漂移時形狀怎麼變」——而它一直在漂，因為 47 µF 的射極
旁路電容要一秒左右才從一記重和弦回復。

雙極電晶體是**雙端口**非線性（兩個共用基極的指數接面），所以它**不可能是 WDF root**
（型別不合，不是難度問題）。`blocks::transistor::Bjt` 提供線性化，本檔跑三節點 Newton。

### 1.1 參考實作不能當參考

細節在 **ADR 035 §3.2**。摘要：BYOD `RangeBooster.cpp` 的回傳值是
`(i_c * RV) * 1e16 - 5e5 - 1.0`，同一組魔數一字不差出現在它自己的 python 原型的
**`plt.plot(...)` 那一行**。`1e16` 之所以必要，是因為那份程式對一顆 **PNP** 餵 NPN 的
Ebers–Moll 方程，整顆電晶體被算在逆向區，`i_c` 落在 1e-16 A。它會發聲，但那不是
Rangemaster 的物理。

所以本顆的方程**全部自行推導**：PNP 極性、三節點 KCL、兩顆電容的梯形伴隨模型、
工作點在 `prepare` 解一次。驗收因此不能靠「與參考比對」，改由**手算工作點**（§3.1）
加**手解 AC 分析**（§3.2）兩層獨立檢查。

### 1.2 鍺不是「換個數字的矽」

BYOD 用 `Is = 10 fA / βF = 200`——那是矽。鍺 OC44 的 `Is` 在 **1e-7 A** 量級，
差七個數量級，而那正是鍺會停在 0.2 V `Vbe`、軟導通、會漏、會漂的原因。

本專案取 `Is = 1.0e-7`（與 `ts-wdf` 選單裡的 1N34A 鍺二極體同一個數量級，ADR 033）、
`βF = 100`（OC44 的 hFE 落在 70–130）、`βR = 2`（合金接面鍺的逆向增益極差——**這正是
飽和柔和而非撞牆的原因**）。這是 **ADR 033 的政策往器件層延伸一格**。

## 2. 規格

### 2.1 Netlist（元件值查自 schematic）

```
Vin —C1(Range)— 基極 ——R1(470k)— 地
                      ——R2(68k)— V+
射極 ——R3(3.9k) ‖ C3(47µ)—— V+
集極 ——RV(10k)—— 地，輸出經 C2(10n) 進放大器輸入
```

真實踏板是**正接地**、−9 V 軌、PNP。這裡把它改寫成正軌參考——**只是符號慣例的改變**，
電路不動。

三個節點的 KCL：

```
基極：  Vb(G1+G2+Gc1) − V+·G2 − Gc1·Vs + s1 + ib = 0
射極：  (Ve−V+)(G3+Gc3) + s3 − ie              = 0
集極：  Vc·Gv + ic                             = 0
```

`(ib, ic, ie)` 與六個跨導由 `Bjt::stamp` 提供。Newton 步長在**接面電壓**上阻尼
（超過 10 個熱電壓就整條步長等比縮回——方向是 Newton 的，長度不是），否則冷啟動
一頭撞進 `exp(v/Vt)` 會衝到 `e^400` 回不來。

### 2.2 工作點在 `prepare` 解，不是空跑出來

參考實作靠 `prepare` 空跑 10,000 個 sample 等暫態穩定。本專案不能這樣做：
`reset()` 會在**音訊執行緒**上被呼叫（切換踏板時），在那裡跑一萬次 Newton 不可接受。

改為：`prepare` 時把兩顆電容**開路**（`Gc = 0`）解一次直流工作點，存起來；`reset()`
只是把節點電壓還原、並把兩顆電容的歷史電流設在平衡值（梯形伴隨模型無電流時
`s = G·v`）。同一個 `newton` 函式兩用——直流解就是「兩顆電容不存在、沒有訊號源」，
所以參數打包成 `Env`，`Env::default()` 恰好是那個意思。

### 2.3 Range 就是那顆電容

`C1`（原廠 5 nF）配上這一級約 10 kΩ 的輸入阻抗 = 3 kHz 高通。**那就是它之所以是
treble booster 的全部理由**，所以 Range 旋鈕直接掃這顆電容，而不是掃一個抽象轉角：

| 位置 | `C1` | 轉角 | 說明 |
| ---- | ---- | ---- | ---- |
| 0 | 2.2 nF | ~7.0 kHz | 常見的加亮改裝 |
| **5** | **5 nF** | **~3.1 kHz** | **原廠** |
| 10 | 47 nF | ~0.33 kHz | 「full range」改裝 |

兩段幾何內插，所以原廠值**剛好落在正午**、每一半在八度上是線性的。走 `Ctl::Trim`
（連續、只到係數不到 sample 路徑，踏板自己以 `REBUILD = 64` 滑動），與 `zendrive`
的 Voice 同一條路。電容改變時歷史電流按 `G_new/G_old` 等比縮放，節點電壓才不會跳。

**白箱紅利**：輸入阻抗是 `β·re`，而 `re = Vt/Ie` 隨射極電流變動——所以**推得越兇，
轉角越動**。一個固定的輸入濾波器接一條曲線做不到這件事。

### 2.4 面板：Boost / Range / Level

真實 Rangemaster **沒有增益控制**（它唯一的旋鈕是輸出音量），它是靠**吉他音量鈕**來
彈的。`Boost` 就是那顆旋鈕，放在我們的訊號鏈搆得到的地方：正午 ±24 dB，正好是一顆
吉他音量鈕的跨度。輸出音量由家族共用的 Level 提供。

**沒有 tone 控制**，因為真實踏板沒有。`post()` 只做 makeup 與輸出耦合
（`C2` 進 1 MΩ 放大器輸入 = 16 Hz）。

## 3. 驗收標準與實測

### 3.1 工作點：四行手算

```
Vb ≈ V+·R1/(R1+R2)              偏壓分壓，被基極電流稍微抬起
Ve  = Vb + Veb,  Veb = Vt·ln(Ie/((1+1/βF)·Is))
Ie  = (V+ − Ve)/R3
Vc  = (βF/(βF+1))·Ie·RV
```

`the_operating_point_is_where_germanium_puts_it` 把這四條全部釘住：`Veb` 落在
0.15–0.26 V（**鍺的招牌**）、`Ie` 在 100–400 µA、`Vc` 與 `α·Ie·RV` 差 < 2 % 且必須
坐在軌的中間（沒有擺幅就沒有這顆踏板）。**下游的每一件事——增益、輸入阻抗、哪一側
先削——都是這四個數字的後果**，所以它們先被獨立驗證，AC 分析才敢用它們。

### 3.2 `cargo test`（lh-dsp 449 → **452**，workspace 全綠，debug 與 release 皆綠）

| 測試 | 標準 | 實測 |
| ---- | ---- | ---- |
| `the_operating_point_is_where_germanium_puts_it` | §3.1 四條 | 全部通過 |
| **`the_linear_response_matches_hand_solved_ac_analysis`** | **3 個 Range × 5 個頻率**，vs 手解三節點複數網路（Cramer），雙線性預扭 | 15 組全數 < 3 % |
| `it_boosts_treble_and_not_bass` | 4 kHz 增益 > 8× 的 100 Hz，且必須 > 20× | 通過 |
| `the_range_knob_moves_the_corner` | Range 10 的 200 Hz 增益 > Range 0 的 5 倍 | 通過 |
| `one_transistor_clips_asymmetrically` | 1.5 kHz 推硬：二次諧波 > 25 % 基頻、三次 > 8 % | 通過（0.48 / 0.17） |
| `cutoff_and_saturation_clamp_at_different_heights` | 正負峰比值必須離開 0.8–1.25 | 通過 |
| `silence_in_silence_out` / `bounded_when_slammed` | 節點電壓有限且在軌內 | 通過 |

**AC 分析那條的手解參考刻意不讀 `Bjt::stamp`**：它從 hybrid-π 的定義自己寫出六個跨導
（`gf = Is·exp(Veb/Vt)/Vt` 等），只共用工作點——而工作點已被 §3.1 獨立釘住。兩層檢查
串起來，就是「這顆踏板的線性行為與它的 netlist 一致」的完整證明。

**諧波測試的頻率選 1.5 kHz = 192000/128**：整數個 sample/週期（基頻不會洩漏進被量測的
諧波 bin，PRD 030 的教訓），而且它在輸入轉角**之上**——treble booster 的失真住在它有
增益的地方，所以那才是機制所在（PRD 031 的教訓）。

### 3.3 `cargo bench`（同一輪，全家族）

| Bench | 中位數 | ÷ screamer |
| ----- | ------ | ---------- |
| `drive_screamer_4x_oversampled` | ~35.9 µs | 1.00（校準） |
| `drive_big-muff_4x_oversampled` | ~85.3 µs | 2.38 |
| **`drive_rangemaster_4x_oversampled`** | **~163 µs** | **4.55** |

**這是家族最貴的一顆，差距不小。** 163 µs ≈ **12 % of the 64-frame deadline**。
價錢的來源是誠實的：三節點 Newton × 2 個 `exp` × ~3 次迭代 × 192 kHz。

實測收斂只要 **2 步**（在 0 / 0.01 / 0.15 振幅下 99.9 % 的 sample 都是 2；狂推到 1.0
才偶爾要 4–8），所以**省不下迭代**。已做的兩項最佳化：

- 逆偏超過 40 個熱電壓的接面直接記為關閉（`e^−40` = 4e-18，對 Jacobian 的貢獻是
  1e-23 S），省掉正向工作區的一次 `exp`；
- 節點收斂容差設 **1e-8 V** 而非 1e-10。Newton 在這裡是二次收斂，步長是
  1e-3 → 1e-9 → 1e-18，1e-10 的門檻整整買一次多餘迭代（**全踏板成本的 25 %**）去
  移動一個 picovolt。1e-8 V 仍比 `f32` 在這幾伏電位上能表示的精度細 40 倍——那才是
  真正的地板（PRD 029 用來界定 oracle 的同一個論證）。第二項量到 ~5 %。

再要更快得換 branch-free 的 3×3 解與更省的指數近似，那是效能專項工作，不在本 Phase。

### 3.4 電平與抗鋸齒

預設旋鈕 **+0.02 dB**（`MAKEUP = 0.176`）。alias floor **−24.1 dB**，釘在 −20：
**家族最高的地板**。理由是拓撲的：截止是一個硬轉折，飽和後級沒有任何低通，而
**ADAA 不適用**（非線性是解出來的電路，不是顯式曲線）。4× 過取樣是唯一防線。

注意 treble booster 的電平**強烈依賴素材**：家族的校準訊號是 220 Hz 正弦，正好落在
輸入轉角之下 —— 同樣旋鈕彈高把位或和弦會明顯更大聲。這是踏板的性質，不是校準失誤。

### 3.5 耳朵（**待使用者驗收**）

- Range 掃全程：原廠 5 nF 在正午，往左更薄更尖、往右變成全頻段 booster。
- Boost 掃全程：低段是乾淨升壓，高段應該有明顯的**偶次**濃度（與二極體踏板一聽就不同）。
- 推 amp 前端的「Clapton/Beano」味——這顆的定位本來就是給後面的東西加料。
- 重和弦後放開：射極旁路電容回復造成的**綻放/回彈**，是這顆與行為模型最不一樣的地方。

## 4. 非目標

- 不建 9 V 電源軌削頂。
- 不建鍺的**漏電與溫漂**（`Ico`）——那是鍺 fuzz 會隨天氣變聲的原因，留給 Phase 08。
- 不追 alias floor（§3.4）。
- 不做真實 Rangemaster 的三段 range 切換開關（本顆的 Range 是連續版，涵蓋同樣的電容）。

## 5. 已知取捨

- **最貴的一顆**（§3.3）。
- **最高的鋸齒地板**（§3.4）。
- `βF = 100` / `Is = 1e-7` 是**型號代表值**，不是某一顆實機的實測；真實鍺電晶體離散
  極大（這正是為什麼有人會挑選電晶體）。計畫 §3 明列這是非目標。
- **不建基極電阻 `rbb′` 與接面電容**：前者在鍺功率較大的型號才顯著，後者在音頻可忽略。
