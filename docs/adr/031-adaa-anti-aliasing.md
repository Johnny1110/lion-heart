# ADR 031: ADAA 抗鋸齒 — 家族級策略，而非單顆優化

狀態：**已採納（2026-07-27）**
關聯：`docs/tone_revolution/phase/06-waveshaper-adaa.md`（來源計畫）、PRD 024（落地
規格）、ADR 003（drive model registry）、ADR 030（tone stack 引擎，同一版一起落地）
影響範圍：**drive 家族全部 12 顆 memoryless 踏板**（`screamer`/`sd1` 除外，理由見下）

## Context

lion-heart 的 memoryless drive 全部走「固定 4× 過取樣 + 逐點取樣的整形函數」。
4× 把折返推高兩個八度、靠半帶濾波器的 ~70 dB 阻帶壓制——**但硬轉角產生的諧波
衰減得太慢，4× 一個人擋不住**。

這不是理論疑慮，是量出來的。以 5 kHz 正弦推進每顆踏板、量非諧波頻點的能量
（`every_memoryless_clipper_is_anti_aliased`）：

| | 改造前 |
|---|---|
| `angry-charlie`（LED 硬切） | **−28.6 dB** |
| `red-charlie` / `monster5150` / `angry-charlie-v2` / `fuzz-face` / `bd2` / `overdrive` | −29 ～ −30 dB |
| `classic` / `evva` | −31 ～ −34 dB |
| `ts9` / `jan-ray` | −37 ～ −41 dB |

**−29 dB 的非諧波地板就是使用者說的「高把位毛躁、沙沙、數位感」。** 它與 tone
stack（ADR 030）是「drive 不滿意」的兩個獨立根源。

## Decision

採用 **ADAA（Antiderivative Anti-Aliasing）**，並且**當成家族級策略**：新的
`blocks::waveshaper` 提供一/二階 ADAA，家族裡**每一個 memoryless 削波級**都接上去。

### 為什麼是 ADAA 而不是「加大過取樣」

把 4× 提到 16× 也能壓地板，但成本是**線性乘上去的**——整條半帶濾波鏈、每一級都
變四倍。ADAA 改的是取樣方式本身：不逐點取 `f(x[n])`，而是先與一個短核做連續時間
卷積再取樣；對線性內插的 `x`，那個卷積在 `f` 的**反導數**上有閉式解。實測（同一
條 4× 過取樣鏈、同一條曲線，只差 ADAA 開關）**一階 +7 %、二階 +28 %** 的整形級
成本，換來 25–50 dB 的地板。

### 階數怎麼選

- **二階**用在有初等二次反導數的曲線：硬切（分段三次多項式）、代數二極體曲線
  （`√(1+x²)`、`asinh`）、正弦、三角摺疊。硬轉角是 ADAA 存在的理由，也是二階
  最划算的地方。
- **一階**用在其餘：`tanh` 的二次反導數是多對數函數，沒有初等形式；量化階梯的
  分段代數不值得那些分支。

### 二階的推導是自己做的

計畫（Phase 06 §2.1）引的是 Parker 等人的發表形式。本專案改為**從定義直接推**：
對三角核 `∫₀¹ (1−s)·f(x₁ + s·Δ) ds` 分部積分，每一半得到

```
A(Δ) = (F₂(x₁+Δ) − F₂(x₁)) / Δ²  −  F₁(x₁) / Δ
y[n] = A(x[n] − x[n−1]) + A(x[n−2] − x[n−1])
```

好處是**兩半各自獨立退化**：`Δ → 0` 時展開 `F₂` 得 `A → f(x₁)/2 + Δ·f′(x₁)/6`，
而那正好是 `½·f(x₁ + Δ/3)`——退化分支是**一次 `f` 求值，沒有巢狀 case**。發表形式
寫成單一分式，退化時要處理 `x₀ ≈ x₂` 與 `x₀ ≈ x₁` 兩層。

正確性不靠推導本身背書：測試同時 pin 住（a）線性 `f` 必須還原三角核的
`(x₀ + 4x₁ + x₂)/6`、（b）每條曲線每個階數對照**定義積分的數值求解**。

### 全程 f64

兩種形式都是差商：兩個相差很多位有效數字的 `F₁` 相減再除以小 `Δ`。f32 在慢速訊號
上會整個吃掉結果。**ADAA 算術與曲線一律 f64**，f32 只在進出口。這是本 ADR 最大的
成本項（見下），但捨掉它就沒有低頻段的精度。

一個例外優化：`tanh` 的 `ln cosh` 是整個改造裡最熱的函數。`|x| > 20` 之後修正項
`ln(1 + e^{−2|x|})` 小於 `|x|` 的一個 f64 ulp——**提前返回不是近似，是同一個數字**，
只是省掉兩個超越函數。高增益踏板的多數 sample 走這條路。

### 群延遲與 dry-sum

一階延遲半個 sample、二階一個。**但它們跑在過取樣率上**，所以 4× 下折算成基頻的
0.125 / 0.25 sample。這很重要，因為好幾顆踏板把**未延遲的 dry 路徑**與整形路徑相加
（`ts9` 的 `x + clipped`、`centaur` 的 clean 路徑）。

計畫 §2.3 把這列為「最容易踩的坑」，並準備了三套補償方案。**實測後三套都不需要**：
最壞情況的梳狀漣漪是 1 kHz 0.01 dB、10 kHz 0.09 dB、16 kHz 0.22 dB，遠低於一把
吉他（cab 在 6 kHz 以上就滾降了）的可聞門檻。數字 pin 在
`dry_sum_comb_error_is_small_at_4x`，並註明**若過取樣倍率下修，這個結論要重驗**。

### `screamer` / `sd1` 不接

它們是 WDF：非線性藏在每個 sample 解出來的方程式裡，不是一條顯式曲線，沒有
`F₁` 可談。它們的地板（−43 / −50 dB）本來就在改造後的中段，列為對照。

### 新踏板 `waveshaper`

同一套基礎設施撐起一顆新踏板：12 條曲線（飽和 4 種、正弦/三角摺疊、量化階梯、
Chebyshev 2–5、fuzz），Drive / Shape / Tone / Level。它是家族裡唯一**不模擬任何電路**
的一顆——模擬的是函數。Shape 是 stepped 選擇器，需要 `Ctl::Shape` 這個新的路由
（`Ctl` 是 `lh-dsp` 私有型別，**零 preset/plugin schema 影響**）。

## Consequences

**好的**

| 踏板 | 改造前 | 改造後 | Δ |
|---|---|---|---|
| `ts9` | −37.4 | **−86.9** | −49.6 dB |
| `angry-charlie` | −28.6 | **−78.8** | −50.2 dB |
| `centaur` | −50.7 | **−78.3** | −27.6 dB |
| `jan-ray` | −41.2 | **−68.1** | −26.9 dB |
| `classic` | −31.5 | **−63.2** | −31.7 dB |
| `evva` | −34.0 | **−59.1** | −25.1 dB |
| `bd2` | −29.9 | **−56.7** | −26.8 dB |
| `overdrive` | −29.8 | **−54.7** | −24.9 dB |
| `fuzz-face` | −29.4 | **−52.7** | −23.4 dB |
| `angry-charlie-v2` | −29.5 | **−42.7** | −13.2 dB |
| `red-charlie` | −29.3 | **−39.6** | −10.3 dB |
| `monster5150` | −29.5 | **−38.0** | −8.5 dB |

- **既有 character pin 一條都沒動、全部通過**，包含 level-norm。計畫 §2.3 預期
  可能要重新 pin 並記錄「微幅 voicing 變動」——沒有發生，因為 dry-sum 的梳狀誤差
  比預期小一個數量級（見上）。這是「同曲線、少鋸齒」該有的結果。

**要付的**

- **成本**：整形級一階 +7 %、二階 +28 %（隔離量測）。整顆踏板的漲幅更大，
  因為 `tanh` 的 `ln cosh` 是 f64 超越函數，而串級踏板有兩三個。最貴的
  `red-charlie`（兩級 ADAA1）在本容器量到 ~33 µs = deadline 的 2.5 %。
  **仍在預算內**（白皮書 §3.2 目標 < 40 % 平均），但這不是免費的。
- **串級的收益打折**：`monster5150`（三級）、`angry-charlie-v2`（兩級）、
  `red-charlie`（兩級）只拿到 8–13 dB。這是**原理上的**：ADAA 假設輸入在 sample
  之間是直線，這對進入**第一個**削波器的訊號成立，對進入第二個的已方波化訊號不
  成立。想再進一步得整條串級一起做連續時間處理，那是另一個題目。
- **f64 進了熱迴圈**。過去 `lh-dsp` 的逐 sample 路徑是 f32（WDF root 在 PRD 022
  還特地從 f64 降到 f32 近似）。這裡方向相反，且理由不同：那邊要的是速度、精度
  已足；這邊差商的抵銷不給 f32 留餘地。
- **曲線與反導數必須成對維護**。新增或修改任何削波曲線，`F₁`（必要時 `F₂`）要跟著
  改，且必須正規化成 `F(0) = 0`（`reset` 依賴這點）。
  `antiderivatives_differentiate_back_to_the_curve` 以中央差分把關。

**沒做的**

- 不降過取樣倍率換 ADAA（計畫 §2.1 列為 bench 後再定）。實測 ADAA 是**加法**不是
  替代品，且降倍率會讓 dry-sum 的梳狀誤差變四倍——不划算。
- `screamer` / `sd1`（WDF）不接，理由見上。
- 不追「完全零混疊」。
- 不搬 Surge / BYOD 的 waveshaper 程式碼（GPL-3）。曲線是公開數學，反導數與 ADAA
  的推導、擬合與分區都是本專案自己算的。
